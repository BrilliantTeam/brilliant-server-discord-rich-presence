# Brilliant-Server-Mod

輝煌伺服器（`brilliantw.net`）的專屬客戶端模組，只在連線至輝煌時啟用。

## 功能

- **Discord 遊玩狀態**：顯示所在分流與遊玩時間，切換分流會自動更新
- **聊天欄選單**：點「☰ 選單」或搜尋，即可使用下列功能
  - 公告、官網文章、聊天紀錄（可搜尋、點擊複製）
  - 常用訊息、頻道設定、自訂指令
  - 分享座標、展示物品、坐下躺下等動作
- **頻道快速發言與分頁**：切換發言頻道；聊天區上方可多選只看聊天、交易、區域、公會、領地
- **私訊視窗**：獨立浮動視窗，可直接回覆、縮放大小並顯示玩家頭像
- **表情符號選單與彩色文字預覽**
- **高清檢視 Discord 圖片**、**配方書辨識伺服器自訂材料**

## 安裝

1. 安裝 [Fabric Loader](https://fabricmc.net/use/installer/) 與 [Fabric API](https://modrinth.com/mod/fabric-api)
2. 把對應**自己遊戲版本**的 jar 放進 `.minecraft/mods/`（支援 1.21.11、26.1 ~ 26.3）
3. 若要顯示 Discord 遊玩狀態，請在背景開啟 Discord 桌面版
4. 開啟遊戲，連上 `brilliantw.net`

設定檔存放在 `.minecraft/config/brilliant-server-mod-*.json`。
