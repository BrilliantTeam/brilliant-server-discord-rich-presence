# brilliant-server-discord-rich-presence

玩家的電腦需要：
1. 裝 [Fabric Loader](https://fabricmc.net/use/installer/)，選擇跟自己遊戲版本一致的版本
2. 把 [Fabric API](https://modrinth.com/mod/fabric-api) 對應版本的 jar 放進 `.minecraft/mods/`
3. 把這個 Mod 對應**自己遊戲版本**編出來的那個 jar 也放進 `.minecraft/mods/`
   （裝錯版本的 jar 會被 Fabric Loader 拒絕載入，並提示版本不相容）
4. 啟動 Discord 桌面客戶端（要在背景執行中，Rich Presence 才連得上）
5. 用 Fabric 的啟動器設定檔開啟遊戲，連上 `brilliantw.net`
